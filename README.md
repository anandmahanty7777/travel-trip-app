# TravelMate — Travel Trip Planner

A React + Vite frontend for a multi-step trip booking flow.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Build check

```bash
npm run build
```

## Features
- Your Details form and field validation
- Date selection with date-order validation
- Guest counters with minimum values
- Conditional travel assistance selector
- Confirmation summary, cancel/reset, success screen and new-trip reset
- Progress stepper and responsive styling

## Notes
- Frontend-only demo; it does not save bookings to a server.
- Completed-step and confirmation illustrations use the supplied CCBP asset URL, so internet access is needed for those images.
- If this is being added to an existing coding-assessment starter project, preserve its prefilled files and merge the components/styles instead of replacing the starter project wholesale.
